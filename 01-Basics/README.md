## Basics

Before jumping into C syntax, it helps to understand what every programming
language fundamentally needs to do.

A programming language needs to provide ways to:

- Store and represent data
- Perform operations on that data
- Take input and produce output
- Control the order in which instructions are executed
  
 ### C as a Programming Language

C is a **procedural programming language**.

In procedural programming, a program is organized around **procedures**
(also known as functions or routines) that describe the steps required
to complete a task.

Instead of focusing primarily on objects and their relationships, the
program focuses on the sequence of operations that need to be performed.

### A Little History

C was developed by **Dennis Ritchie** at **Bell Labs (AT&T)** in the
early 1970s. The language took shape around **1972** and was initially
created for system programming and the development of the Unix operating
system.
