### Purpose

Each code file is designed to help understand a specific topic through practical implementation. Instead of limiting the file to a single example, it contains multiple programs and variations that apply the concepts covered in that topic.

The difficulty and complexity of the code follow the structure of the parent folder. For example, `01_Basics` contains only fundamental C programs, while later folders progressively introduce more advanced concepts and implementations.

The goal is to build understanding through **concept → implementation → practice**, while gradually increasing programming complexity.
### Learning Approach

The section begins with simple programs and gradually introduces the fundamentals of working with values and data in C.

The initial sequence is:

1. **`Hello_world.c`** — Write and run the first C program.
2. **`assign_a_value.c`** — Learn how to declare variables and assign values directly.
3. **`update_a_value.c`** — Modify previously assigned values and understand how variables change.
4. **`output_value_send_by_user.c`** — Take values as input from the user instead of assigning them directly in the program.
5. **`taking_datatypes_from_user.c`** — Practice taking different types of input from the user.
6. **Shape calculations** — Apply variables, arithmetic operations, and user input to calculate the area and circumference/perimeter of different shapes, including a **square, rectangle, and triangle**.
7. **`size_of_datatypes.c`** — Explore the memory size of different C data types using `sizeof`.

The purpose is not to enforce a strict problem-solving sequence. The early programs provide enough foundation to understand the basic mechanics of C, after which problems can be attempted in any order.

This section intentionally follows a **low-rules, breathable learning environment**: understand the concept, implement it, experiment with variations, and move on when comfortable. The focus is on building practical understanding rather than following a rigid checklist.
